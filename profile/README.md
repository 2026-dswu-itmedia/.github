# 덕성여자대학교 IT미디어공학전공 제14회 졸업전시회 웹사이트
> The 14th Graduation Exhibition Dept. of IT Media Engineering Duksung Women’s Univ.

<br>

보이지 않던 연결이 모습을 드러내는 순간, 새로운 가능성이 시작됩니다.

NEX:US는 ‘연결’을 의미하는 NEXUS와 ‘우리’를 뜻하는 US가 만나 탄생한 이름입니다. 서로 다른 관심과 시선에서 출발한 우리의 작업은 각자의 자리에서 확장되어 왔고, 이번 전시를 통해 하나의 흐름으로 이어집니다.

코드와 감정, 데이터와 상상, 기술과 인간. 서로 멀리 떨어져 있는 것처럼 보였던 요소들은 끊임없이 영향을 주고받으며 새로운 관계를 만들어냅니다. 우리는 그 사이에 존재하지만 쉽게 드러나지 않았던 연결의 지점을 발견하고, 각자의 방식으로 시각화하고자 했습니다.

지난 4년간 쌓아온 배움과 고민, 실험과 실패, 그리고 성취는 서로 다른 형태의 결과물로 나타났습니다. 인공지능과 데이터, 가상현실과 인터랙션, UI/UX를 비롯한 다양한 기술적 탐구와 예술적 시도가 만나 하나의 전시 공간을 구성합니다.

NEX:US는 완성된 결과를 보여주는 데서 그치지 않습니다.
각자의 작은 아이디어가 서로 연결되고, 또 다른 가능성으로 확장되는 하나의 지점입니다.

이곳에서 작품과 작품 사이, 기술과 사람 사이, 그리고 서로 다른 생각 사이에 놓인 보이지 않는 선들을 발견해보시기 바랍니다.

우리의 연결은 여기에서 끝나지 않고, 다시 새로운 세계를 향해 이어집니다.
